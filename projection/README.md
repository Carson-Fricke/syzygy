# Native provider projection

Plans complete and partial tool groups from neutral call and result identities.
The provider adapter supplies the already scoped messages and renders the
returned message references into its wire representation.

- The streaming decoder frames SSE and assembles provider completions with
  readable deltas, opaque reasoning, and private tool arguments.
- `Cargo.toml` declares the library and its serialization dependency.
- `src/` contains the projection and streaming decoders.
